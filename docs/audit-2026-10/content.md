## 1. 조사 방법과 한계

- **라이브 사이트 요청은 총 40회**, 순차·0.3초 간격으로 했다: 사이트맵 3개, 정적·SSR 페이지 20개, 블로그 12편, `GET /api/portfolio` 2회, 접근 가능 여부 확인 3회. POST와 폼 제출은 하지 않았다.
- **공식 네이버 블로그**(blog.naver.com/simple_cube): RSS 1회와 글 12편을 m.blog.naver.com으로 받았다. 복제율은 공백을 지운 10자 단위 조각(shingle)의 교집합 비율로 계산했다(`scripts/`).
- **SERP**: WebSearch는 **미국 중심 엔진**이어서 네이버나 구글 한국 순위를 대표하지 않는다. `site:simplecube.net`, "심플큐브", "심플큐브 포토부스"는 아예 무관한 결과만 나왔다. 피키픽과 무피(MUFI)는 직접 받아 확인했다. 포토픽·지금이순간·사진한조각·모멘트컷은 해외 IP 차단(HTTP 403)으로 **검색 스니펫으로만** 확인했다 → [미검증].
- **검색량**: 키워드 도구에 접근할 수 없어 수치를 쓰지 않았다. 상대적 우선순위만 제시한다. 실제 월간 검색수는 §7-e 절차로 확인해야 한다.

### 3-1. 판정: doorway 위험은 **줄었지만 해소되지 않았다**

검색하는 사람 입장에서 판단 기준은 하나다. "대구 사람이 `/daegu/`에서 `/rental/`에 없는 무엇을 얻는가?" 지금은 이동 시간 한 줄과 유명 장소 목록뿐이다.

- **[관찰] 공통 문구**: 도시명을 빼고 8자 단위로 비교하면, 각 페이지 본문의 40~43%가 10개 페이지 전체에 공통이다. 쌍별 유사도는 0.28~0.39다(`scripts/region_similarity.py`). 본문은 3,100~3,500자다.

- **[관찰] FAQ**: 도시마다 같은 질문 4개를 도시명만 바꿔 자동 생성한다. 관리자가 지역 FAQ를 등록하는 구조는 있지만, DB의 CHECK 제약과 API 허용 목록 때문에 **실제로는 등록할 수 없다**(§2-3).

### 3-3. 구조 개선안

1. **`RegionUniqueInfo`에 필수 props를 추가한다** (`src/components/region/RegionUniqueInfo.astro`):
   - `localCases: { date; venue; type; photo; href }[]` (실사례, 최소 3건)
   - `travelFee: { area; fee }[]` (금액)
   - `branch: { address; manager; placeUrl }`
   - `localCases`가 3건 미만이면 사례 섹션 대신 가까운 지점 허브로 안내하고, 해당 페이지에 `noindex` 적용을 검토한다.
2. **"주요 출장 가능 행사장" 표기를 바꾼다.** 경험 근거가 없는 유명 장소 목록이므로 "출장 가능 장소 예시"로 이름을 바꾸거나, 실제로 진행한 곳만 남긴다.
3. **통합 규칙(제안)**: 최근 12개월 실제 진행 5건 이상 + 사진이 있는 도시만 단독 페이지를 유지한다. 나머지는 지점 허브로 301 통합한다. 예시(결정은 오너 몫):
   - 충주·청주·천안 → `/daejeon/`(대전·세종·충청)
   - 울산 → `/busan/`(부산·울산·경남)
   - 광주 → `/jeonju/`(전북·광주)
4. 지역 페이지 하단 CTA(`busan.astro:221` 등)가 범용 `/contact/`로 간다. 해당 지점의 카카오 채널(부산 `_RxgxkPb`, 대전 `_xgqgyb`, 전주 `_TPxjxoG`)과 지역이 미리 선택된 문의 양식으로 바꾼다.

1. **가격 투명성**: 경쟁사는 시간·주말·출장비를 공개한다. 우리는 `/pricing/`과 `/rental/`에만 "~부터" 가격이 있고, 웨딩 페이지에는 없다.

### 5-4. 피키픽과의 관계: 결정이 필요하다

**[관찰]**
- picky-pic.com 푸터: "상호 주식회사 피키글로벌 · 사업자번호 772-86-02811 · 서울 성동구 성수이로18길 31, **풍림테크원 205,206호** · 02-338-**9181**". 본문: "2020년 설립 … **16,000건 이상**".
- 심플큐브 서울 매장 상세주소도 "풍림테크원 205, 206호"다(`docs/SEO_RECOVERY.md` 2026-10 섹션). 대표번호는 02-338-**9180**이고, 사이트는 "2019년 설립 … 16,000건 이상"을 쓴다.
- 미발행 GEO 글이 피키픽을 홍보한다. 엔카 사내행사는 심플큐브 네이버 블로그(07-13)와 피키픽 포트폴리오에 **양쪽 모두** 실려 있다.

**[가설]** 같은 회사나 관계사가 두 브랜드를 운영하는 것으로 보인다.

**위험**
- 두 도메인이 "포토부스 대여·팝업스토어 포토부스·기업행사 포토부스·인생네컷 대여"를 동시에 노려 서로 잠식한다.
- 같은 실적("16,000건")과 같은 사례를 두 브랜드가 각자 주장하면, 소비자 신뢰와 표시·광고 관점에서 문제가 된다.

**결정 요청** (오너)
1. 브랜드별 키워드 분담. 예: 심플큐브 = 웨딩·지역 지점·가족/학교 행사, 피키픽 = 브랜드 팝업·기업·AI·구매.
2. "16,000건"을 어느 브랜드 실적으로 볼지 정한다. 브랜드별로 나누거나 "그룹 누적"으로 명시한다.
3. 같은 사례를 두 사이트에 중복 게재하지 않는다.

이 결정에 따라 `/popup/`·`/corporate/`에 대한 투자 수준이 달라진다.

**졸업식 (`graduation`, 코드 수정 3 배포 후)**
1. **졸업식 포토부스는 언제 예약해야 하나요?** — 2월 졸업식·학위수여식과 8월 학위수여식은 날짜가 몰립니다. 일정이 정해지면 바로 문의해 주세요. [가능하면 "○주 전" 기준 입력]
2. **학교 로고와 교명을 넣을 수 있나요?** — 네. 학교 로고·교명·졸업 연도·축하 문구를 포토스트립에 무료로 넣어 드립니다.
3. **학생이 많아도 사진을 다 뽑을 수 있나요?** — 행사 시간 동안 매수 제한 없이 무제한 인화합니다. 인원이 많으면 부스 대수를 늘리는 것을 권장합니다. [기준 입력]
4. **체육관·강당에 설치하려면 무엇이 필요한가요?** — 콘센트 [ ]구, 설치 공간 [ ]m × [ ]m, 행사 [ ]분 전 반입이 필요합니다. [실측 기준 입력]
5. **사진을 휴대폰으로도 받을 수 있나요?** — QR 코드로 바로 내려받을 수 있어 앱 설치 없이 저장·공유할 수 있습니다.
6. **학교 예산으로 결제할 수 있나요?** — [견적서·세금계산서·카드 결제 가능 여부 입력]

**렌탈 (`rental`)**
1. **포토부스 대여에는 무엇이 포함되나요?** — 장비 설치·철거, 맞춤 포토스트립 디자인, 현장 무제한 즉석 인화, 디지털 원본 전달이 기본입니다. 웨딩은 전담 스텝 2인이 운영하고, 행사 운영 스태프는 옵션입니다.
2. **어떤 부스를 골라야 하나요?** — 브랜드 행사는 외관 랩핑이 가능한 팝업·모듈 부스, 웨딩과 고급 행사는 원목 부스(Edge·Round)를 많이 선택합니다. 공간과 콘셉트를 알려주시면 추천해 드립니다.
3. **최소 몇 시간부터 대여할 수 있나요?** — 행사는 최소 2시간부터이며 일·주·월 단위 장기 대여도 가능합니다. 웨딩은 본식 90분 전에 설치를 시작해 예식 시작 후 30분까지 운영합니다.
4. **출장 가능한 지역과 출장비는요?** — 서울·부산 시내는 출장비가 없습니다. 그 외 지역은 가격 안내의 지역별 출장비 표를 확인해 주세요. [표 작성 후 `/pricing/#travel` 링크]
5. **취소하면 위약금이 있나요?** — 계약 후 14일 이내이면서 행사 60일 전까지 취소하면 전액 환불됩니다. 그 밖에는 행사일 60일 이상 전 30%, 30~59일 전 50%, 29일 이내 100%의 위약금이 있습니다.
6. **예약은 얼마나 미리 해야 하나요?** — 주말과 성수기(봄·가을 웨딩, 연말 행사)에는 예약이 몰립니다. 날짜가 정해지면 바로 문의해 주세요.

**가격 (`pricing`)**: 부가세 포함 여부 / "최대 할인가 42만원"의 조건 / 주말·공휴일 할증 / 지역별 출장비 / 시간 추가 단가 / 계약금·잔금 시점 / 견적 회신 시간(지역 페이지의 "평일 30분 내 회신"이 사실일 때만) / 취소 위약금(렌탈 5번 재사용). 앞의 6개 항목은 **오너가 실제 값을 넣어야** 의미가 있다. 숫자가 없는 가격 FAQ는 경쟁사 대비 효과가 없다.
