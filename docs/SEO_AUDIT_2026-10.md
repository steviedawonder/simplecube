## 1. 지금 노출 상태 진단 (2026-10-30 실측)

### 1-1. 정상인 것 (다시 손댈 필요 없음)

- 네이버 Yeti·다음·Bing·구글·AI 봇(GPTBot·ClaudeBot·PerplexityBot 등 13종) 모두 200 + 같은 HTML. Vercel 방화벽 차단 없음.
- 구조화 데이터 문법 오류 0 (validator.schema.org), Lighthouse SEO 점수 전 페이지 100.
- 운영 배포 = 저장소 최신 커밋. 서버 오류는 30일간 1건(10/25 `/pricing` DB 연결 끊김 → 500).

### 1-2. 노출을 막고 있던 것 (영향 큰 순)

1. **사이트 블로그가 멈춰 있고, 있는 글의 절반이 네이버 블로그 복제본**
   - 사이트 블로그 마지막 글 2026-08-07 → 12주째 0편. 같은 기간 공식 네이버 블로그는 실제 현장 후기 16편 발행.
   - 사이트 글 12편 중 6편이 네이버 원문과 91~100% 같고, 원문보다 13분~2일 늦게 올라감 → 네이버는 사이트 쪽을 유사문서로 보고 노출에서 빼고, 구글도 중복으로 판단할 수 있습니다.
   - 블로그 12편 중 11편이 서비스 페이지로 가는 링크 0개, 7편은 블로그 목록 외에 들어오는 링크가 없음 → 10/4 서치콘솔 "색인 20 / 미색인 119" 의 주요 원인으로 보입니다.
2. **사실 정보가 채널·페이지마다 다름** (검색엔진과 AI가 "어느 게 맞나"를 판단하지 못함)
   - 영업시간: 사이트 평일 10–18시 / 네이버 플레이스 매일 10–18:30 / 카카오맵 매일 24시간 / 스키마 Mo–Fr.
   - 서울 네이버 플레이스: 상호 "심플큐브"(포토부스 없음), 업종 "이벤트,파티", 홈페이지가 `www.` 주소, 소개 오타 "Basic Hapniness", 메뉴·톡톡·예약 0.
   - 업력 "8년"(가격표·기업행사) vs 2019년 설립 / 블로그 "5년간", 실적 사이트 16,000건 vs 네이버 광고 문구 14,000건, 서울 페이지 "서울 1,500건".
   - AI 답변이 실제로 짚은 불일치: 인화 시간 8초 vs 15초, 설립 2019 vs 인크루트 2017, 본점 위치(인크루트는 마포 망원로).
   - **피키픽(picky-pic.com)** 이 같은 주소(성수 풍림테크원 205·206호), 연속 전화번호(02-338-9181), 같은 "16,000건 이상", 같은 키워드·사례를 씀 → 두 사이트가 서로 경쟁하고, AI 는 두 업체를 구분하지 못합니다(§6 결정 필요).
3. **네이버 승부처(플레이스)가 정비되지 않음** — 7/28 진단 그대로: 네이버 웹문서 노출은 하루 800~1,000회인데 클릭은 거의 0. "심플큐브" 검색 시 우리 브랜드 광고는 없고 쿠팡 광고만 노출. 다음 웹마스터도구·Bing·구글 비즈니스 프로필은 미등록.
4. **페이지에 "답"이 없음** — 웨딩·팝업·졸업·지역 10개·홈에 가격 텍스트가 0개. 그래서 AI 답변이 행사 가격을 "50만원~"(실제 55만원~)으로 잘못 인용. 팝업·렌탈·기업행사·졸업식 4개 페이지가 같은 FAQ 6개를 보여줌(원인: DB 제약 버그 — 졸업식·지역 FAQ 는 저장 자체가 불가능했음).
5. **렌더링·속도** — 스크롤 애니메이션(GSAP)이 본문을 투명하게 시작해, 스크롤하지 않는 검색엔진 렌더러에는 홈 본문 83%·브랜드 66~76%·문의 최대 90%가 빈 화면. 모바일 Lighthouse 성능 홈 27~30 / 웨딩 50~59 / 팝업 51~52 / 블로그 38~45. 홈 이벤트 팝업이 LCP 를 5.5초로(팝업 없을 때 1.2초), 숨은 슬라이드 13장(3.1MB)을 첫 화면에서 한꺼번에 받음.
6. **측정 오류** — 실제 문의 1건이 GA4·네이버 광고 전환 2건씩, 입력 오류로 전송도 안 된 제출이 1건, 허니팟에 걸린 봇이 2건으로 집계. GA4 에 지정된 핵심 이벤트는 사이트가 보내지 않는 것뿐. 카카오 클릭은 /contact/ 서울 버튼 1개만, 전화 클릭은 0 집계. 네이버 애널리틱스 페이지뷰 일부(실측 14회 중 4회)가 대행사 광고 키로 새어 나감.
7. **기타 기술 위험** — `determined-goldstine-iota.vercel.app` 이 사이트 전체를 200 으로 복제 노출(네이버 블로그 글 2편이 이 주소로 링크), DB 일시 오류 시 14개 페이지 + 블로그가 500, SSR 응답에 charset 없음, 웨딩 페이지 공개 HTML 에 관리자 안내 문구, 블로그 목차 링크 49개가 엉뚱한 제목으로 이동.

## 3. 검증 (배포 전 로컬에서 실제 실행)
