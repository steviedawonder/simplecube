## 1. ⚡ 가장 먼저: 전환 측정 켜기 (이거 없이 광고비 쓰면 다 샘)

사이트 코드에는 이미 문의 완료 시 `generate_lead` 이벤트가 발사됩니다(배포 완료). GTM에서 받아서 각 플랫폼에 "전환"으로 연결만 하면 됩니다.

### GTM 설정 (tagmanager.google.com → GTM-5JG6SWNF)
- [ ] **트리거**: 유형 "맞춤 이벤트" / 이벤트 이름 `generate_lead`
- [ ] **GA4 이벤트 태그** 연결 → GA4에서 해당 이벤트를 "핵심 이벤트(전환)"로 표시
- [ ] **네이버 검색광고 전환** → searchad.naver.com에서 전환추적 스크립트 발급 → GTM 커스텀HTML 태그로 연결 (★ 파워링크 성과 측정, 최우선)
- [ ] **메타 픽셀 태그** → 이벤트 `Lead` (메타 픽셀 먼저 생성 필요, 아래 3번)
- [ ] (선택) **구글애즈 전환 태그** → 구글 광고 집행 시
- [ ] **미리보기(Preview)로 테스트** → 문의 제출 시 `generate_lead` 뜨는지 확인 → **게시(Submit)**

### 확인 위치 (전환이 찍히는 곳)
| 채널 | 확인 경로 |
|------|-----------|
| 네이버 파워링크 | searchad.naver.com → 보고서 → 전환수 |
| GA4 | analytics.google.com → 보고서 → 참여도 → 전환 |
| 메타 | business.facebook.com → 이벤트 관리자 |

## 3. 신규 고객 "창출" — 메타(인스타) 웨딩 캠페인

검색광고는 이미 원하는 사람만 잡음. 신규는 메타로 창출. (웨딩 라인이 메타와 궁합 최고)

### 준비
- [ ] 메타 비즈니스 계정 + **픽셀 생성** → 사이트에 연결 (GTM 통해)
- [ ] 기존 고객·문의자 명단 업로드 → **유사타겟(Lookalike) 1%** 생성

### 캠페인 세트 (웨딩)
- **목표**: 리드/문의 (전환 캠페인)
- **타겟**: 만 25~38세 여성 × 관심사(약혼/웨딩/신혼/웨딩홀/웨딩준비) × 운영도시 반경 30km × 유사타겟
- **소재**: 실제 행사 영상 릴스(세로 9:16), 결과물 캐러셀, 후기 캡처. "지역 + 웨딩 포토부스"
- **네거티브**: 이미 전환한 사람 제외

### 리타겟팅 (가장 싼 전환) — 최우선
- [ ] 사이트 방문자(최근 30일) + 인스타 상호작용자 → 리타겟 캠페인
- 월 방문 2,408명 × 이탈 51% = **버려지던 1,200명 재접촉**

## 4. 예산 배분 (월 100만 기준, 조절 가능)

측정(1번) 세팅 후 시작. **집중 → 데이터 → 재배분** 원칙.

### 1단계 (1개월차 · 측정+집중)
| 채널 | 배분 | 용도 |
|------|------|------|
| 네이버 파워링크(논브랜드 확장+네거티브+착지매핑) | 55만 | 수요 수확 |
| 리타겟팅(메타+네이버 GFA) | 25만 | 가장 싼 전환 회수 |
| 네이버 플레이스 광고 | 20만 | 로컬 노출 |
| 구글·메타 신규창출 | 0(보류) | 2단계 |

### 2단계 (2~3개월차 · 확장)
- 전환 데이터 확보 후 **CPA 낮은 채널로 재배분**
- 메타 웨딩 신규창출 30~40만 투입 (성수기 봄·가을 비중↑)

### 효율 원칙
1. 리타겟 먼저 2. 수확 극대화 후 창출 3. 지역·시간 타겟 4. 네거티브 5. 소액테스트→승자에 몰아주기
