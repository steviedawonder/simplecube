## 1. 네이버 스마트플레이스 등록·최적화 (최우선)

### 1-1. 출장업종의 주소 처리법

출장 포토부스는 "방문 손님이 오는 매장"이 아니라 "출장을 나가는 사업장"이다. 네이버 스마트플레이스는 **실제 사업장 주소 + 사업자등록증**이 있어야 등록되므로, 다음 원칙을 따른다.

- **반드시 실제 주소가 있는 지점만 플레이스로 등록한다.** 직영 지점(서울 본점·부산·대전·전주)은 각각 사업장/오피스 주소로 등록. 사무실·창고·작업실 주소라도 사업자 소재지면 가능.
- **출장 권역(대구·광주·울산·천안·청주·충주)은 별도 플레이스를 만들지 않는다.** 가짜 주소로 등록하면 네이버가 "유령 업체"로 판단해 노출 제한·삭제 위험. 대신 가까운 직영 지점 플레이스의 **소개글·키워드·블로그 글**로 권역을 커버한다(예: 대전 플레이스 소개글에 "충청권 청주·충주·천안 출장").
- 등록 시 **"출장 서비스" 옵션**을 켜고, 가능하면 매장 노출보다 **방문/출장 가능 지역**을 명시한다.
- 주소 비공개가 필요하면(작업실 노출 꺼림) 플레이스 설정에서 **상세주소 비공개 + 지역(동/구)만 표시**를 활용. 단, 위치 핀은 있어야 지역 검색에 잡힌다.

### 1-2. 지점별 등록 전략 (4개 플레이스)

| 플레이스 | 업체명(권장) | 대표 키워드 | 소개글 권역 언급 |
|---|---|---|---|
| 서울 본점 | 심플큐브 포토부스 서울본점 | 서울 포토부스 대여, 웨딩 포토부스 | 수도권 출장 |
| 부산 | 심플큐브 포토부스 부산점 | 부산 포토부스 대여, 부산 웨딩 포토부스 | 울산 출장 권역 |
| 대전 | 심플큐브 포토부스 대전점 | 대전 포토부스 대여, 대전 팝업 포토부스 | 청주·충주·천안 충청권 출장 |
| 전주 | 심플큐브 포토부스 전주점 | 전주 포토부스 대여, 전북 포토부스 | 광주·호남권 출장 |

- 4개 플레이스는 **동일 브랜드·동일 사업자(또는 지점 사업자)**로 등록하되, 업체명은 위처럼 "브랜드 + 업종 + 지점명"으로 통일해 브랜드 검색 시 한 번에 노출되게 한다.
- 본사 사업자 1개로 다지점 운영 시: 네이버는 같은 사업자번호로 복수 플레이스 등록을 허용하나, 주소가 실제로 달라야 한다. 지점 주소가 없으면 무리하게 만들지 말고 본점 1개 + 블로그/광고로 지역 커버.

### 1-3. 업체명 작성 규칙

- **금지**: 업체명에 키워드 도배("부산포토부스대여웨딩기업행사심플큐브") → 네이버 노출 제한/반려.
- **권장 형식**: `심플큐브 포토부스 [지점명]` (예: `심플큐브 포토부스 대전점`)
- 사업자등록증·간판과 일치해야 심사 통과가 빠르다.

### 1-4. 카테고리 설정

대표 카테고리 1개 + 추가 카테고리로 검색 커버리지를 넓힌다.

- **대표 카테고리**: `포토부스` 또는 `행사대행`(네이버 카테고리에 "포토부스"가 있으면 우선 선택)
- **추가 카테고리(가능 범위)**: `이벤트대행`, `웨딩서비스`, `행사기획`, `사진/영상`
- 대표 카테고리는 검색 매칭에 가장 큰 영향을 주므로, 주력(웨딩/기업/팝업 중 가장 매출 비중 큰 것)에 맞춘다. 심플큐브는 출장 포토부스 전문이므로 `포토부스/행사대행` 우선.

### 1-6. 사진·영업정보

- **대표 사진(첫 장)**: 포토부스 부스 외관 + 행사장 분위기가 함께 나온 가로형 고화질. 텍스트 박힌 홍보 이미지보다 실제 현장 사진이 클릭률·신뢰도가 높다.
- **사진 최소 20장 이상**: 부스 외관 / 인화 사진 샘플 / 맞춤 프레임 디자인 / 웨딩 현장 / 팝업 현장 / 기업행사 현장 / 운영 스태프 / 장비 셋업 과정.
- **메뉴(상품) 등록**: "웨딩 패키지", "팝업/브랜드 패키지", "기업행사 패키지", "반일/종일 대여" 등을 메뉴로 올리고 간단 설명 + 가격대(또는 "문의") 표기. 메뉴 등록 업체가 검색·전환에서 유리.
- **영업정보**: 영업시간(예: 평일 10:00–19:00, 주말 행사 출장), 휴무일, 대표 전화, 주차/출장 가능 여부.
- **편의/특징 태그**: "출장 서비스", "예약", "주차" 등 해당 항목 모두 체크.

### 1-7. 네이버 예약 / 톡톡 연동

- **네이버 톡톡 연결**: 플레이스에 톡톡을 붙여 상담 인입을 네이버 안에서 받는다(현재 카카오 채널로 받는 문의를 네이버 검색 사용자에게도 열어주는 효과). 응답률이 노출에 영향.
- **네이버 예약**: 행사 상담/현장 답사 예약을 받는 형태로 설정 가능. 예약 기능이 있는 플레이스는 "예약" 필터·상위 노출에 유리. 최소한 "상담 예약" 형태라도 켠다.
- **스마트콜**: 가상번호로 전화 유입 추적 → 어느 키워드·채널에서 전화가 오는지 데이터 확보.

### 1-8. 리뷰 확보 동선

리뷰(방문자 리뷰 + 블로그 리뷰)는 플레이스 순위의 핵심 신호다.

- **행사 종료 직후**가 골든타임: 현장 마무리 시 담당자에게 "네이버 플레이스 리뷰 부탁" QR/링크 전달.
- **영수증/예약 기반 방문자 리뷰** 유도: 네이버 예약·결제 이력이 있어야 방문자 리뷰 작성 가능하므로, 계약/예약을 네이버 예약으로 받으면 리뷰 동선이 자연스럽게 열린다.
- **블로그 리뷰 캠페인**: 웨딩·팝업 고객(특히 인플루언서·브랜드 담당자)에게 블로그 후기 작성을 부탁하고, 작성 글에 플레이스 위치 태그를 걸도록 안내.
- **사진 리뷰 우대**: 부스에서 뽑은 인화물·현장 사진을 리뷰에 첨부하도록 권유(사진 리뷰가 노출·신뢰에 유리).
- **답글 100%**: 모든 리뷰에 정중한 답글. 응답 활동이 활성 업체 신호.
- ⚠️ 대가성 허위 리뷰·자가 리뷰는 금지(적발 시 노출 제재). 실제 고객 후기에만 집중.

## 2. 네이버 블로그 12주 콘텐츠 캘린더

### 2-1. 제목·키워드 작성 요령

- 제목 형식: `[지역/행사] + 핵심키워드 + 후킹` (예: `대전 웨딩 포토부스 대여, 하객 반응 터진 후기`)
- 한 글당 **타깃 키워드 1개**에 집중(제목·첫 문단·소제목에 자연 배치). 키워드 도배 금지.
- 사진: 직접 촬영한 현장 사진(타사·웹 이미지 금지, 유사문서 처리 위험). 사진 파일명·대체텍스트에 키워드 반영.
- **위치 태그(지도)**: 글 하단에 해당 지점 플레이스를 지도 태그로 삽입 → 블로그↔플레이스 연결 강화.
- 같은 키워드로 단기간 양산 금지(유사문서). 지역·행사유형을 바꿔가며 다양화.
- 글 끝에 항상 CTA: 인스타/카카오채널/플레이스 예약 링크.

## 3. 네이버 서치어드바이저 등록

목표: `simplecube.net`을 네이버 웹 검색에 정상 색인시키기.

### 3-1. 사이트 등록 단계

1. `searchadvisor.naver.com` 접속 → 네이버 계정(가급적 `simple_cube@naver.com` 비즈 계정) 로그인.
2. **웹마스터도구 → 사이트 등록** → `https://simplecube.net` 입력(www/non-www, http/https 중 실제 운영 URL 정확히. Vercel은 https·non-www가 보통).

### 3-2. 소유확인 (둘 중 1)

- **HTML 파일 업로드**: 네이버가 주는 `naver{코드}.html`을 사이트 루트(`/public/`)에 올려 `https://simplecube.net/naver{코드}.html` 접근되게 한 뒤 "확인". (Astro는 `public/` 폴더에 두면 루트로 배포됨.)
- **메타태그**: `<meta name="naver-site-verification" content="..." />`를 사이트 `<head>`(공통 레이아웃)에 삽입 후 배포 → "확인". Astro에서는 공통 Layout의 `<head>`에 추가.

### 3-3. 사이트맵·기타 제출

1. **요청 → 사이트맵 제출**: `https://simplecube.net/sitemap-index.xml` 입력 후 제출.
2. **요청 → RSS 제출**(블로그 RSS가 있으면).
3. **검증 → robots.txt**: `Allow` 및 `Sitemap: https://simplecube.net/sitemap-index.xml` 한 줄 포함 확인. 네이버 봇(Yeti) 차단 없는지 점검.
4. **요청 → 웹페이지 수집**: 핵심 페이지(메인, 지역 랜딩, 서비스) URL 개별 수집 요청으로 색인 가속.
5. 등록 후 **검색 노출/사이트 진단** 리포트를 1~2주 뒤 확인해 색인 누락·오류 처리.

> 네이버 블로그는 별도 색인 체계라 서치어드바이저 불필요하지만, **블로그 글에 simplecube.net 링크**를 넣어 웹사이트 신뢰도를 보강한다.

## 4. 파워링크 / 플레이스 광고 단기 전략

블로그·플레이스가 자리잡기 전 1~3개월간 즉시 유입을 만드는 보조 수단. 예산은 직영 4개 지점 권역에 집중.

### 4-1. 추천 키워드 우선순위

**1순위 (전환 의도 높음 · 즉시 집행)**
- `[지역] 포토부스 대여` — 서울/부산/대전/전주 (직영) + 대구/광주/울산/천안 (출장)
- `웨딩 포토부스 대여`, `[지역] 웨딩 포토부스`

**2순위 (행사유형 · 중간 경쟁)**
- `팝업 포토부스`, `브랜드 포토부스`, `기업행사 포토부스`, `행사 포토부스 대여`

**3순위 (롱테일 · 저비용 고효율)**
- `[지역] 졸업식 포토부스`, `무인 포토부스 대여`, `포토부스 대여 비용`, `[지역] 돌잔치 포토부스`

### 4-2. 지역 키워드 효율 논리

- **지역+업종 키워드는 검색량은 작지만 전환율이 높고 클릭단가(CPC)가 싸다.** "포토부스 대여"(광역)는 비싸고 경쟁이 치열하므로, 예산 적을 때는 **지역 한정 키워드로 ROAS를 확보**한다.
- **직영 지점 4곳**: 파워링크 + **플레이스 광고(지역소상공인광고/플레이스 상위노출)** 병행 → 검색 결과 상단 + 지도 상단 동시 점유.
- **출장 권역 6곳**: 플레이스가 없으므로 **파워링크(랜딩=해당 지역 페이지)**만 집행. 광고 클릭 → `simplecube.net`의 지역 랜딩페이지로 연결(이미 SEO 랜딩 보유).
- 키워드별 **지역 랜딩페이지로 정확히 연결**(부산 키워드→부산 페이지)해 품질지수↑·CPC↓.
- **시즌 가중**: 웨딩(봄·가을), 졸업식(2월·8월), 기업행사·연말(11~12월)에 예산 상향. 팝업은 연중.
- 측정: 스마트콜 가상번호 + 랜딩 폼 전환 추적으로 키워드별 CPA 산출 → 효율 낮은 키워드 정리.

## 5. 채널 통합 (상호링크 설계)

모든 채널이 서로를 가리키게 만들어 브랜드 신호와 전환 동선을 강화한다.

```
            simplecube.net (허브)
          /     |       |      \
    네이버블로그  플레이스   인스타   카카오채널
        \       |        |      /
              당근(지역)
```

- **simplecube.net(허브)**: 푸터/문의 영역에 네이버 블로그·플레이스(지점별)·인스타·카카오채널 링크 모두 노출.
- **네이버 블로그**: 프로필·각 글 하단에 simplecube.net, 해당 지점 플레이스 지도태그, 인스타, 카카오채널 링크. 글 본문에서 인스타 릴스 임베드.
- **네이버 플레이스**: "홈페이지" 필드에 simplecube.net, "SNS" 필드에 인스타·블로그 연결. 소식/공지에 블로그 최신 글 링크.
- **인스타(지점 계정)**: 프로필 링크를 simplecube.net(또는 링크모음)으로. 스토리 하이라이트에 "네이버예약/플레이스" 추가. 지점 계정 ↔ 본점 계정 상호 태그.
- **카카오톡 채널**: 채널 홈에 simplecube.net·플레이스·블로그 버튼. 상담 시 플레이스 리뷰 요청 링크 발송.
- **당근 동네업체**: 대전→부산·전주·서울로 확대. 업체 프로필에 블로그·인스타 링크. 당근은 지역 신뢰 + 리뷰 확보 채널로 활용.
- **UTM 태그**: 채널별 링크에 `?utm_source=naverblog` 등 부착해 유입 출처 분석.
