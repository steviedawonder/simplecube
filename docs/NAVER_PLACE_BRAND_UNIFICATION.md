# 심플큐브 네이버 플레이스 정비 · 브랜드 정체성 통일 가이드

> 작성 배경(2026-07-28 진단): 색인·기술 SEO는 정상. 진짜 병목은 **"클릭 유입"**이며, 네이버에서는
> 홈페이지 웹문서가 파워링크·플레이스·블로그 아래 묻혀 **노출은 많아도(하루 800~1,000) 클릭이 거의 0**.
> → 네이버 승부처는 **플레이스**. 그런데 현재 **브랜드 정체성이 채널마다 달라** 검색·고객 모두 혼란.
>
> 이 문서는 두 가지만 다룬다: **① 브랜드 정체성 통일 → ② 네이버 플레이스 정비.**
> 블로그 12주 캘린더·파워링크·상호링크 설계는 기존 [`NAVER_LOCAL_SEO.md`](./NAVER_LOCAL_SEO.md)를 그대로 사용.

# Part 1. 브랜드 정체성 통일

## 1-1. 문제: 서로 다른 3개의 카테고리 단어

심플큐브가 채널마다 다른 정체성으로 노출되고 있다. 이 셋은 **고객·가격·검색의도가 전부 다른 별개 카테고리**다.

| 단어 | 고객이 떠올리는 것 | 가격 인식 | 심플큐브에 맞나? |
|---|---|---|---|
| **즉석사진** | 무인 자판기, 셀프 촬영 | 저가 (수천 원) | ❌ 아님 |
| **인생네컷** | 프랜차이즈 방문형 부스 | 저가 | ❌ 아님 |
| **포토부스 대여 / 렌탈** | 행사에 부르는 프리미엄 출장 서비스 | 고가 (50만원~) | ✅ **이것** |

카카오맵의 "즉석사진"은 **심플큐브를 싸구려 자판기로 보이게 만들어** 고단가 행사 고객을 놓치고, 검색엔진에도 "이 업체 정체가 뭐지?" 하는 혼란을 준다.

## 1-2. 결정: 정체성은 **"포토부스 대여"** 하나로 통일

- **대표 카테고리(검색용)** = `포토부스` / `포토부스 대여` — 전 채널 상호·업종을 여기에 맞춘다.
- **차별화 수식어(브랜딩용)** = **"원목 프리미엄"** — 뉴스에도 나온 실제 물리적 차별점(원목 포토부스). 소개글·태그라인에 일관되게 사용해 플라스틱 부스 경쟁사와 구분되는 **소유 가능한 포지션**을 만든다.
- **한 줄 정체성**: *"심플큐브 — 2019년부터 14,000건, 원목 프리미엄 포토부스 대여 (웨딩·팝업·기업행사)"*

> "즉석사진"·"인생네컷"은 상호·업종·소개글에서 제거한다. (블로그 글 소재로 `인생네컷 대여` 키워드를 노리는 건 별개 — 그건 검색 유입용이라 OK)

## 1-3. NAP 표준값 (모든 채널이 이 표와 100% 일치해야 함)

| 지점 | 표준 업체명(플레이스) | 전화 | 인스타그램 | 카카오 채널 |

**공통 표준값**
- 브랜드 표기: `심플큐브` (한글) / `SIMPLE CUBE` (영문) — `심플 큐브`(띄어쓰기)·`심플큐브즉석사진` 금지

# Part 2. 네이버 플레이스 정비 (실행)

> 목표: 흩어진/틀린 플레이스를 **표준 정체성으로 통일**하고, 검색·전환에 유리하게 최적화.
> 신규 등록 세부(주소 처리·소개글 전문·리뷰 동선)는 [`NAVER_LOCAL_SEO.md` §1](./NAVER_LOCAL_SEO.md) 참조. 여기서는 **정비 관점**만.

## 0단계 — 현황 감사 (먼저 확인)

1. 네이버앱/PC에서 **"심플큐브"** 검색 → 플레이스가 뜨는지, 뜬다면 **이름이 뭔지**(즉석사진? 포토부스?) 확인.
2. **"심플큐브 대전"**, **"성수 포토부스"**, **"대전 포토부스"** 도 검색해 중복/누락 파악.
3. **네이버 스마트플레이스**(smartplace.naver.com) 로그인 → 내 업체 목록 확인.
   - 이미 있으면 → **소유권 있는지** 확인 (없으면 "내 업체 등록/소유권 주장").
   - 없으면 → [`NAVER_LOCAL_SEO.md` §1](./NAVER_LOCAL_SEO.md) 절차로 신규 등록.
4. 발견한 상태를 아래 표로 기록:

| 검색어 | 플레이스 뜸? | 현재 이름 | 소유권 | 조치 |
|---|---|---|---|---|
| 심플큐브 | | | | |
| 심플큐브 대전 | | | | |
| 성수 포토부스 | | | | |

## 1단계 — 소유권 확보

- 스마트플레이스에서 각 지점 업체의 **소유권 인증**(사업자등록증 기반). 소유권이 없으면 이름·정보를 못 고친다.
- 성수(서울 본점)·대전은 카카오에 이미 실주소가 있으니, 네이버에도 같은 주소로 소유권 인증 가능.

## 2단계 — 업체명 교정 (정체성 통일의 핵심)

- `심플큐브 즉석사진` → **`심플큐브 포토부스 서울본점`**
- `심플큐브 대전 즉석사진` → **`심플큐브 포토부스 대전점`**
- 부산·전주도 표준명으로 등록/정렬.
- 규칙: `심플큐브 포토부스 [지점명]` 형식. **키워드 도배 금지**(`부산포토부스대여웨딩…` ❌ → 네이버 반려/제재).

## 3단계 — 카테고리·소개글·사진·메뉴

- **대표 카테고리**: `포토부스` (없으면 `행사대행`) / 추가: `이벤트대행`·`웨딩서비스`·`사진영상`.
- **소개글**: 첫 문장에 **"원목 프리미엄 포토부스 대여 · 14,000건"** 차별점을 넣고, 지역+행사유형+포토부스를 자연스럽게. 지점별 문안은 [`NAVER_LOCAL_SEO.md` §1-5](./NAVER_LOCAL_SEO.md) 그대로 사용(단, 헤더에 "원목 프리미엄" 한 줄 추가).
- **대표 사진**: 원목 부스 외관 + 행사 분위기 가로형 실사(홍보문구 박힌 이미지 ❌). 총 20장+.
- **메뉴(상품)**: 웨딩/팝업·브랜드/기업행사/반일·종일 패키지 + 가격대(또는 "문의").

## 4단계 — 전환 장치

- **네이버 톡톡** 연결(현재 카카오로 받는 상담을 네이버 사용자에게도 개방).
- **네이버 예약**("행사 상담/현장답사 예약") — 예약형 플레이스가 상위·필터 노출 유리.
- **스마트콜**(가상번호) — 키워드별 전화 유입 추적.

## 5단계 — 리뷰 확보

- **행사 종료 직후**가 골든타임: 담당자에게 플레이스 리뷰 QR/링크 전달.
- 방문자 리뷰는 네이버 예약/결제 이력 필요 → 계약을 네이버 예약으로 받으면 동선이 열림.
- 사진 리뷰 우대, **모든 리뷰 답글 100%**. 대가성 허위 리뷰 금지(제재).

## 원칙 (제재 회피)

- **정체성은 "포토부스 대여" 하나.** 즉석사진·인생네컷을 상호/업종에서 제거.
